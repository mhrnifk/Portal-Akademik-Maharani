Portal Layanan Akademik

Website Portal Layanan Akademik merupakan proyek web client yang dibuat untuk memenuhi tugas Pertemuan 5 — Responsive & Accessible Web Client.

Deskripsi Proyek

Website ini menyediakan antarmuka layanan administrasi akademik mahasiswa dengan desain responsif, struktur HTML semantik, dan aksesibilitas dasar.

Fitur

* Navigasi utama ke bagian halaman.
* Tiga kartu layanan akademik.
* Form permohonan layanan.
* Validasi dasar menggunakan HTML.
* Desain responsif untuk mobile, tablet, dan desktop.
* Indikator fokus untuk navigasi keyboard.
* Pemeriksaan website menggunakan Browser DevTools.

Teknologi

* HTML5
* CSS3
* Chrome DevTools

Pengujian

Website diuji menggunakan Browser DevTools pada ukuran viewport berikut:

Perangkat	Lebar viewport
Mobile	360 px
Tablet	768 px
Desktop	1280 px

Pengujian mencakup tampilan responsif, struktur HTML, validasi form, navigasi keyboard, dan pemuatan resource.

Batasan

Website ini merupakan web client statis. Form belum terhubung ke backend atau database sehingga data permohonan belum disimpan.
